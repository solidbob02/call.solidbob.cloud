기존 10건은 한별텔레콤 시나리오라 **무효**다(`w1-golden-set-10` 참고). 4개 도메인 기준으로
처음부터 다시 만들고 50건까지 늘린다.

## 정해야 할 것 — 도메인별 비율 (미정)

```
금융보험 · 다산콜센터 · 쇼핑 · 질병관리본부  →  50건을 어떻게 나눌 것인가
```

균등(각 12~13건)이 단순하지만, **F-2 가 금융보험·쇼핑에만 적용**되므로 그 두 도메인에
케이스가 더 필요할 수 있다. 팀에서 정한 뒤 여기에 적는다.

## 스펙 ([5.3절](/docs/05/))

한 건에 들어가야 하는 것 — **도메인**, 고객 발화, **발화 종료 시각**, 정답 문서 ID(`FIN-3.2` 형식),
오답 후보, 컴플라이언스 위반 삽입 여부, 개인정보 패턴(P1~P7) 삽입 여부, (해당 시) F-2 케이스.

## 주의

- 정답은 **논리 위치(`doc_id`)로** 라벨링한다. 청크 ID 로 적으면 4주차 청킹 3종 비교 때 라벨이 깨진다
- **F-2 케이스는 규정 작성자가 아닌 사람이 만든다.** 같은 사람이 만들면 판정 정확도가 자기충족적 수치가 된다
- 50건은 **잠정 베이스라인용**이다. CI 에 박히는 공식 기준선은 3주차 150건이다

## 완료 조건

50건 작성 + 작성자와 다른 사람의 검수.
