팀명: **SOLIDBOB** (3인)

## 7.1 담당

| 담당 | 인원 | 범위 |
|---|---|---|
| **AWS·인프라** | 정성윤 | Node.js WebSocket 게이트웨이, Google STT 연동, 화자 분리, **C-5 마스킹**, MySQL 스키마, Docker·배포, 레이턴시 측정 인프라, **CI 운영** |
| **백엔드·AI** | 류준 | ES 인덱스 설계·하이브리드 검색·리랭킹, 트리거 판정, 생성 모듈, 컴플라이언스 분류기, **F-2 게이트**, 평가 하네스 설계 |
| **앱·프론트엔드** | 장민석 | React 대시보드(자막·카드·경고·종결 모달), WebSocket 클라이언트, 데모 시나리오, 결과 시각화 |
| 공동 | 3인 | 골든셋 작성·라벨링, 발표 자료 |

## 7.2 부하 경고 — 반드시 읽을 것

**류준이 백엔드와 AI를 동시에 맡고 있어 구조적으로 과부하다.** [4·5주차 핵심 실험](/docs/08/)과 F-2가 모두 이 한 사람에게 걸려 있다.

완화 조치를 문서에 고정한다.

| 조치 | 내용 |
|---|---|
| C-5를 정성윤에게 배정 | 전사 직후 처리 지점이라 STT 파이프라인 담당이 자연스럽다. 정규식 중심이라 AI 전문성 의존도가 낮다 |
| **CI 운영을 정성윤에게 이관** | 류준은 1주차에 하네스 **설계**만 하고, 이후 운영·유지는 정성윤이 맡는다 |
| 골든셋은 3인 공동 | 라벨링은 도메인 이해만 있으면 되므로 분산 가능하다 |
| 장민석이 시각화 담당 | matplotlib 성능 곡선·레이턴시 분포를 프론트 담당이 가져간다 |
| **F-2는 조건부** | 류준의 코어 작업이 지연되면 F-2를 설계 문서로 전환한다 ([8절 체크포인트](/docs/08/)) |

## 7.3 인터페이스 계약 우선

1주차에 모듈 간 스키마를 확정한다. 이것이 병렬 작업의 전제 조건이다.

```json
// 전사 이벤트 (마스킹 적용 후)
{
  "call_id": "c_001",
  "speaker": "customer",
  "text": "카드번호는 **** 입니다",
  "masked": [{"type": "P2", "span": [7, 11]}],
  "is_final": true,
  "utterance_end_ms": 3100
}

// 추천 카드
{
  "call_id": "c_001",
  "trigger_at_ms": 3150,
  "cards": [
    {
      "title": "프로모션 할인 적용 시점 안내",
      "summary": "신규 가입 할인은 가입 다음 달 청구서부터 반영됩니다.",
      "source": {"doc": "요금제약관", "clause": "3.2"},
      "score": 0.87
    }
  ],
  "internal_latency_ms": 780,
  "e2e_latency_ms": 1240
}

// 종결 판정 (F-2)
{
  "call_id": "c_001",
  "closure_type": "해지",
  "reason": "고지 완료",
  "evidence": {"위약금_안내": true, "잔여할부_안내": false, "고객확인_기록": false},
  "verdict": "blocked",
  "missing": ["잔여할부_안내", "고객확인_기록"],
  "source": {"doc": "응대매뉴얼", "clause": "7장"}
}
```
