| 리스크 | 영향 | 대응 |
|---|---|---|
| **AI Hub 승인 지연** | 데모·파이프라인 검증 지연 | 1주차 즉시 신청. **[4.2절](/docs/04/) 핵심 실험은 텍스트 레벨 오류 주입이므로 승인과 무관하게 진행 가능** — 영향 범위가 좁다 |
| **화자 분리 정확도 미달** | C-1~C-3, C-5 전체의 성능 상한선이 됨 | **[V1] 확인 완료 — AI Hub 데이터 전부 모노.** 채널 분리 불가, Google STT diarization 필수 사용. **데모는 물리 2채널(브라우저 2대)로 우회**하고, 모노 데이터 기반 오프라인 평가는 diarization 오차가 포함된 한계로 명시 |
| **류준 부하 집중** | 코어와 F-2가 한 사람에게 걸림 | [7.2절](/docs/07/) 완화 조치 적용. F-2 조건부 착수 |
| Google STT 한국어 성능 미달 | 파이프라인 품질 저하 | 벤치마크 사전 확인 ([9.6절](/docs/09/)). 오류 내성 설계 자체가 주제이므로 오류가 많아도 실험은 성립 |
| STT API 비용 초과 | 예산 소진 | 반복 실험은 배치 모드, 실시간 데모만 스트리밍. **무료 크레딧/무료 한도 내로만 사용하도록 이중 캡** — ① GCP 콘솔 쿼터로 STT 요청량 하드 리밋 ② `services/gateway`에 `STT_MAX_SECONDS_PER_DAY`/`_MONTH` 애플리케이션 가드 추가(COST-1, `.env.example`) |
| GPU 미확보 | 생성 모델 크기 제약 | V2로 1주차 확인. 소형 모델로 대응, 카드 요약은 대형 모델 불필요 |
| 레이턴시 목표 미달 | 데모 설득력 저하 | 목표 미달해도 **측정하고 원인을 분해한 기록**이 있으면 성과 |
| 범위 과다 | 미완성 | F·G·H·I는 조건부. B(검색)와 E(평가), C-5를 절대 사수 |
| **개인정보 노출** | 자막·DB에 평문 저장 | **C-5를 3주차 코어로 포함.** P1~P7 누락 0건 |
| 약관 저작권 | 공개 시 문제 소지 | 원문 전재 대신 요약·해석 + 출처 표시 |
| 민감 도메인 표현 | 과장·부적절 서술 | [부록 A](/docs/12/) 준수. 개별 사건 실명·세부 인용 금지 |
