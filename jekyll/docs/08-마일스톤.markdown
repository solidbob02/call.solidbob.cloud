### 성공 조건 — 재설정

> **STT 오류 내성 실험([4.2절](/docs/04/)) + 검색 품질 개선 수치.** 이 두 가지가 나오면 프로젝트는 성공이다. **F-2는 달성 시 추가 성과로 본다.**

이전 리비전은 성공 조건을 F-2에 걸었으나, F-2는 조건부 항목이므로 부적절하다. 폴백으로 가더라도 프로젝트가 실패로 읽히지 않도록 기준을 재설정한다.

**범위 관리 규칙**: 6주차 종료 시점에 코어 기준선을 통과하지 못했다면 F·G·H·I를 착수하지 않는다. **C-5만 예외로 코어에 포함되므로 3주차에 반드시 들어간다.**

**진행 방식:** 매 스프린트 시작일 스프린트 플래닝 → 스프린트 종료일 리뷰·회고 → 결과는 [진행상황](/progress/) 페이지에 기록.
