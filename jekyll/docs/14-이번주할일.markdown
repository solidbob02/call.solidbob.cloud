## 오늘 처리

1. **AI Hub 회원가입 + 휴대폰 인증 + 데이터 신청** — 승인에 시간이 걸린다
2. **V1 확인** — AI Hub 데이터셋 상세 페이지에서 채널 구성(스테레오/모노) 확인. 이것이 3주차 설계를 좌우한다
3. **V2 확인** — GPU 가용 여부. 생성 모델 크기와 레이턴시 예산이 여기 걸린다

## 1주차 초반

4. **인터페이스 스키마 3종 확정** — 전사·카드·종결. 병렬 작업의 전제
5. **골든셋 10개 시범 작성** — 라벨링이 실제로 가능한지 검증. 여기서 막히면 지식베이스 구성을 바꿔야 한다
6. **골든셋 스펙에 발화 종료 시각 필드 포함** — 없으면 트리거 지표를 채점할 수 없다

## 팀 확인 사항

7. 투입자원 목록 밖 도구 사용 가능 여부 — 본 기획서는 목록 안에서만 구성했으므로 현재는 해당 없음
8. [7.2절](/docs/07/) 부하 완화 조치에 대한 3인 합의

세부 진행은 [8주 마일스톤](/docs/08/)의 칸반 보드, 완료 기록은 [진행상황](/progress/)에서 확인하세요.
