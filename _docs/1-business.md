## 1) 사업 목적

콜센터 상담원은 고객의 질문을 들으면서 동시에 사내 문서를 검색해야 한다. 약관·매뉴얼·공지가 여러 곳에 흩어져 있어 숙련도에 따라 응대 품질이 크게 갈리고, 검색하는 동안 통화는 멈춘다.

본 사업은 **통화가 진행되는 중에 시스템이 대화를 듣고, 고객이 방금 물은 내용에 필요한 문서를 상담원 화면에 자동으로 띄운다.** 상담원은 검색창에 타이핑하지 않는다.

기존 콜센터 프로젝트 대부분은 통화 *후* 녹음 파일을 처리한다(전사 → 요약 → 티켓 생성). 그것은 배치 파일 변환 파이프라인이며 실시간성이 필요 없다. 본 사업은 통화 *중* 개입한다.

| | 사후 처리형 | 실시간 개입형 (본 사업) |
|---|---|---|
| 입력 | 완성된 녹음 파일 | 0.3초 단위 스트리밍 조각 |
| 질의 | 완결된 문장 | 미완성 발화 |
| 레이턴시 요구 | 없음 | 1초 이내 |
| RAG 난이도 | 낮음 (일반 RAG) | 높음 (트리거 판정 + 오류 내성) |
| 제품 범주 | 통화 분석 | Agent Assist |

## 2) 주요 사업 내용

| 블록 | 내용 | 우선순위 |
|---|---|---|
| A | **실시간 음성 처리** — 스트리밍 STT, 화자 분리(고객/상담원), 발화 구간 검출 | 필수 |
| **B** | **자동 문서 추천 (RAG 핵심)** — 검색 트리거 판정, 하이브리드 검색(형태소+임베딩), 리랭킹, 근거 기반 요약 카드, 출처 표시, 근거 부족 시 "관련 문서 없음" 반환 | **사수** |
| C | **실시간 컴플라이언스 감지** — 확정적 보장 표현("무조건", "100% 환불"), 불필요한 개인정보 요구, 필수 안내 누락, 권장 대체 표현 제시 | 후순위 |
| D | **통화 후 처리** — 상담 요약, 문의 유형 분류, 후속조치 추출, 지식베이스 공백 리포트 | 후순위 |
| **E** | **평가 하네스** — 골든셋 자동 채점, STT 오류율별 성능 곡선, 레이턴시 분포, 기준선 미달 시 CI 실패 | **사수** |

범위가 넘칠 경우 **D → C 순으로 축소**한다. B(검색)와 E(평가)는 어떤 경우에도 사수한다.

### 화면 구성

| 영역 | 내용 |
|---|---|
| 좌 | 실시간 자막 — 화자 구분 표시 |
| 중 | 추천 카드 — 제목 / 근거 요약 / 출처(문서·조항) / 유사도 |
| 우 | 컴플라이언스 경고 — 감지 문구, 발생 시각, 권장 대체 표현 |

## 3) 기대 효과

| 효과 | 내용 | 확인 방법 |
|---|---|---|
| 응대 지연 감소 | 상담원이 문서를 찾는 동안의 침묵을 시스템이 대신 메운다 | p95 레이턴시 ≤ 1,000ms |
| 숙련도 편차 흡수 | 신입 상담원도 숙련자와 같은 근거 문서를 같은 시점에 본다 | Recall@5 / MRR |
| 컴플라이언스 리스크 감소 | 확정적 보장·개인정보 과요구를 발화 즉시 경고 | 감지 재현율 ≥ 0.90 |
| 지식베이스의 자가 개선 | 답을 못 찾은 질문이 쌓이면 어떤 문서가 없는지 드러난다 (D-4 공백 리포트) | 검색 실패 질문 집계 |
| 오류 내성 확보 | STT 오인식이 있어도 검색이 무너지지 않는다 | 오류율별 성능 곡선 |

마지막 항목이 본 사업의 대표 실험이다. 음성인식은 반드시 틀리므로("해지"→"해제", "요금제"→"요금 제"), **오류가 섞인 질의에서도 정답 문서를 찾아내는 것**이 실제 성패를 가른다.

## 참고 — 제품 범주와 선행 사례

본 사업이 다루는 것은 **Agent Assist** 라는 확립된 제품 범주다. Amazon Q in Connect, Google Agent Assist, LG CNS FCC RT-Advisor, KT A'Cen 등 국내외 상용 제품이 존재한다. 이는 위험이 아니라 근거다 — 실무에서 실제로 필요한 문제라는 뜻이며, 기능 명세와 아키텍처를 비교 검증할 대상이 있다는 뜻이다.

특히 국내 사례에서 반복 지적되는 난점이 본 사업 설계의 출발점이다.

- 통화에 카드번호·주민번호 등 민감정보가 섞인다 → 마스킹 기준 필요
- LLM 이 회사에 없는 정책을 말하거나 권한 밖 보상을 약속할 수 있다 → 지식베이스 범위와 답변 금지 조건 명시
- 한국어 통화는 존댓말·지역 억양·배경 소음·업계 약어가 섞인다 → **STT 정확도가 일정하다고 가정하면 안 된다**
