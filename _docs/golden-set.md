> 현재 상태: **미착수**. 도메인 확정 후 10건 시범 작성으로 라벨링 가능성을 먼저 검증한다.
> 여기서 막히면 도메인을 바꿔야 한다.

## 시나리오 한 건의 구성

```
- 고객 발화 스크립트
- 이 시점에 표시되어야 할 문서 ID   ← 정답 라벨
- 표시되면 안 되는 문서 ID          ← 오답 후보 (혼동 유발용)
- 컴플라이언스 위반 삽입 여부
- 트리거가 발동해야 할 시점(ms)
```

목표 규모: 1주차 50건 → 2주차 150건.

## 음성 확보

| 순위 | 방법 | 비고 |
|---|---|---|
| 1 | AI Hub 데이터에서 유사 시나리오 매칭 | 승인 필요, 1주차 즉시 신청 |
| 2 | TTS 합성 | 승인 지연 대비책 |

자체 통화 녹음은 하지 않는다 (개인정보).

## STT 오류 주입

프로그램으로 세 가지 변형을 준다.

| 유형 | 예 |
|---|---|
| 자모 치환 (유사 발음) | 해지 → 해제 |
| 띄어쓰기 변형 | 요금제 → 요금 제 |
| 동음이의 치환 | 위약금 → 위약 금 |

오류율 0 / 5 / 10 / 15 / 20 % 구간으로 성능 곡선을 만든다.

## 지식베이스 도메인 (미확정)

| 후보 | 장점 | 단점 |
|---|---|---|
| 통신사 요금제 약관 ← 권장 | 공개, 조건 복잡, 문의 유형 다양 | 분량 방대 |
| 보험 약관 | 조건 중첩 극심, 컴플라이언스 이슈 풍부 | 전문용어 장벽 |
| 카드 혜택 조건 | 실적 조건 판정 난이도 높음 | 갱신 빈번 |

약관 원문은 검색 인덱스에만 저장하고, 화면·공개 문서에는 요약·해석 + 출처만 싣는다.
