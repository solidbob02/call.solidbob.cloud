# 골든셋 — v1 (10개)

[데이터 확보 계획 5.3절](/docs/05/)의 1주차 목표(10개)를 채운 초안이다.
`knowledge-base/`의 실제 문서 ID(도메인 접두어 포함)를 그대로 참조하므로, 지식베이스
문서가 바뀌면 이 골든셋도 같이 갱신해야 한다.

> **2026-08-26 전면 재작성.** 데모 도메인을 가상 통신사 "한별텔레콤" 단일 시나리오에서
> 실제 확보 데이터 4종(금융보험·다산콜센터·쇼핑·질병관리본부)으로 한정하면서, 이전
> 버전(`TERM-*` 등 통신 도메인 문서 ID를 참조)이 전부 무효가 됐다. 근거:
> `_project/decisions/004-데모-도메인-4종-확정.md`.

## 파일

- `v1-10.json` — 항목 10개. 스키마는 아래 참고.

## 스키마 (5.3절 "골든셋 스펙에 포함할 항목" 그대로)

| 필드 | 설명 |
|---|---|
| `domain` | `finance` / `dasan` / `shopping` / `health` 중 하나 — [1.4절](/docs/01/) 4개 도메인 |
| `customer_utterance` / `agent_utterance` | 고객 또는 상담원 발화 스크립트 |
| `utterance_end_ms` | 발화 종료 시각 — [4.1절](/docs/04/) 트리거 채점(0~1,500ms 허용창)용 |
| `expected_doc_ids` | 이 시점에 표시되어야 할 정답 문서 ID (도메인 접두어 포함, 예: `FIN-TERM-2.2`) |
| `distractor_doc_ids` | 표시되면 안 되는 오답 후보 문서 ID (같은 도메인 내 근접 조항) |
| `compliance_violation` | C-1~C-4 위반 삽입 여부와 유형 |
| `pii_patterns` | P1~P7 개인정보 패턴 삽입 여부 (C-5 채점용) |
| `f2_case` | 처리 유형 + 근거 필드 충족 상태 + 기대 판정 (F-2 케이스만 — **금융보험·쇼핑 도메인에만 존재**, 다산콜센터·질병관리본부는 F-2 미적용) |

## 모듈별 분포 (10개)

| 모듈 | 개수 | 내용 |
|---|---|---|
| B (검색) | 3 | 카드 부정사용 보상(금융보험) · 대중교통 실시간 안내(다산콜센터) · 반품 배송비(쇼핑) |
| C-1·C-2 (컴플라이언스) | 2 | 확정적 보장 표현(금융보험) · 불필요한 민감정보 요구(질병관리본부) |
| C-5 (마스킹) | 2 | 구분자 있는 표준 형태(쇼핑, P1+P2) · **구분자 없는 붕괴 형태**(다산콜센터, P4 — 주 실패 모드) |
| F-2 (종결 게이트) | 3 | 상품해지 승인/차단(금융보험) · 반품 차단(쇼핑) — [POLICY](/docs/02/) 필드 구조가 도메인마다 다름을 검증 |
