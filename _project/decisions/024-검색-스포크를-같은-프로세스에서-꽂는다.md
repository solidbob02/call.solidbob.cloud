# 024 — 검색 스포크를 HTTP 가 아니라 같은 프로세스에서 꽂는다

**날짜**: 2026-08-27
**작성**: 장민석 (브랜치 `server`)
**관련**: `decisions/012`(담당 디렉터리 분리) · `server/.importlinter` 계약 2

## 맥락

류준 님이 `EsBm25Retriever`(`RetrievalPort` 구현)를 만들었는데, **`server/` 의 요청 경로에서
그걸 쓸 방법이 정해져 있지 않았다.** `POST /hub/search`·`/hub/recommendations` 는 계속 501 이었다.

`server/.importlinter` 계약 2 가 **`hub`·`masking`·`closure_gate`·`core` → `ai` import 를 금지**한다.
그래서 «어떻게 꽂는가» 가 열려 있었다.

## 선택지

| | 방법 | 비용 |
|---|---|---|
| A | **같은 프로세스** — 합성 루트(`main.py`)에서 `ai/` 구현을 주입 | `server` 컨테이너가 `ai/` 코드와 `elasticsearch` 패키지를 함께 실어야 한다 |
| B | **HTTP** — `ai/` 를 별도 서비스로 띄우고 `server` 가 호출 | `ai/` 에 웹 서버를 새로 만들어야 하고, 네트워크 홉이 [4.1절](/docs/04/) p95 ≤1,000ms 예산을 먹는다 |
| C | 그대로 501 로 둔다 | 검색이 있는데 못 쓴다 |

## 결정

**A. 같은 프로세스에서 `main.py` 가 꽂는다.**

## 근거 — 설계가 이미 답을 갖고 있었다

**① `ai/` 는 서비스가 아니라 라이브러리다.** `ai/requirements.txt` 주석이 그렇게 적고 있다 —
*"의존성(fastapi·uvicorn)은 `server/requirements.txt` 에 있다."* HTTP 표면도, 웹 프레임워크
의존성도 **없다.** B 를 고르면 없는 서비스를 새로 만드는 일이 된다.

**② `main.py` 는 계약 대상이 아니다.** `.importlinter` 의 `root_packages` 는
`hub`·`masking`·`closure_gate`·`core` 넷이다. `main.py` 는 거기 없다 — **합성 루트**라서다.
계약 2 는 «허브가 스포크를 모른다» 를 지키라는 것이지 «프로세스를 나눠라» 가 아니다.

**③ 이미 같은 패턴이 돌고 있다.** `scripts/run_eval.py` 가 평가 경로에서 하는 일을
`main.py` 가 요청 경로에서 한다. `main.py` docstring 도 애초에 이렇게 적혀 있었다 —
*"스포크 구현체는 여기서 `dependency_overrides` 로 꽂는다. 이 파일만 양쪽을 안다."*

**④ 지연 예산.** [4.1절](/docs/04/)이 내부 처리 p95 ≤1,000ms 를 요구한다.
B 는 홉을 하나 더 만든다. 지금 그 예산을 쓸 이유가 없다.

## 결과 (실측, 2026-08-27)

```
GET  /health                 spokes: ["masking","closure_gate","retrieval"]
POST /hub/search             501 → 200   "반품 배송비는 누가 부담하나요"
                             → SHOP-TERM-4.2 (15.99) · SHOP-MANUAL-1.3 (13.65) · SHOP-TERM-4.3 (7.9)
POST /hub/recommendations    501 (trigger B-1 미구현 — 3주차)
```

## 안전장치

- **못 꽂으면 조용히 501 로 남는다.** `ELASTICSEARCH_URL` 이 없거나 `ai/`·`elasticsearch` 를
  import 할 수 없으면 주입하지 않는다. **임시 구현을 만들지 않는다** — 빈 목록은
  「관련 문서 없음」(B-6)과 구분되지 않는다(절대 원칙 10)
- **`server` CI 는 그대로 돈다.** `ai/` 의존성이 없는 환경에서도 `main.py` 가 import 되도록
  실패를 예외로 올리지 않는다. `/health` 의 `spokes` 가 비어 있어 밖에서 구분된다
- **기동 시 ping 하지 않는다.** ES 가 잠깐 내려갔다고 서버가 못 뜨면 **자막·마스킹까지 멈춘다.**
  붙지 못하면 검색 요청에서 실패하고, 그건 「등록 안 됨(501)」과 구분되는 정직한 오류다

## 되돌리는 법

1. `main.py` 의 `_wire_retrieval` 을 지운다 — 프로바이더 기본값이 501 이라 그대로 돌아간다
2. B 로 가려면 `ai/` 에 FastAPI 앱을 만들고, `server/apps/hub/adapter/outbound/` 에
   `RetrievalPort` 를 구현하는 **HTTP 어댑터**를 둔다(그건 `server/` 안이라 계약 위반이 아니다)

## ⚠ 남은 것

**배포가 갈려 있다는 서술과 어긋난다.** `CLAUDE.md` 는 `server.solidbob.cloud` ·
`ai.solidbob.cloud` 두 도메인을 적어 뒀는데, A 를 택하면 **한 컨테이너에 둘이 함께 실린다.**
지금은 `ai/` 에 서비스 실체가 없어 모순이 드러나지 않지만, **정성윤 님이 배포를 짤 때
정해야 한다** — 도메인 서술을 고칠지, 나중에 B 로 갈지. [미결 항목](/open-items/)에 올렸다.
