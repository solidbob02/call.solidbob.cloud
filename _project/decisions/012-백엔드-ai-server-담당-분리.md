# 012. 백엔드·AI 를 `ai/`(류준) · `server/`(장민석) 로 나눠 맡는다

- **날짜**: 2026-08-26
- **상태**: 채택
- **관련**: `_project/decisions/005-팀-개편-4인-체제.md`(공동 작업 결정 — 이 문서가 갱신한다),
  `CLAUDE.md` §1·§7, `.claude/rules/rfp-harness.md` §2

## 맥락

2026-08-26 `decisions/005` 로 팀을 4인으로 개편하면서, 류준·장민석의 백엔드·AI 는
**"기능별로 나누지 않고 둘이 함께"** 하기로 정했었다. 근거는 당시 코드가 없어서
나눌 경계 자체가 없었다는 것이다.

같은 날 `fastapi/` 가 `server/` · `ai/` 두 서브도메인으로 분리되면서
(사용자 지시, `server.solidbob.cloud` · `ai.solidbob.cloud` DNS 에 맞춤) **나눌 경계가
실제로 생겼다.** 의존 방향도 `ai → server` 한쪽으로 고정돼 있고
`server/.importlinter` 계약이 역방향을 막는다.

## 결정

**디렉터리 경계를 그대로 담당 경계로 쓴다.**

| 담당 | 디렉터리 | 하는 일 |
|---|---|---|
| **류준** | `ai/` | 데이터셋 모델 학습, 청킹, BM25, 리랭크, 임베딩, LangChain·LangGraph, 평가 하네스 |
| **장민석** | `server/` | 파이프라인 구축, 클린 아키텍처, 계약(포트·DTO), 요청 경로 배선 |

`decisions/005` 의 "기능별 분할 없음"은 **이 문서로 갱신된다.** 다만 둘 다 백엔드·AI
역할인 것은 그대로이며, 경계에 걸친 작업(계약 변경 등)은 여전히 함께 정한다.

## 근거

- 나누지 않기로 했던 이유(경계가 없음)가 사라졌다. 디렉터리·의존 방향·`.importlinter`
  계약·영역별 `CLAUDE.md` 가 이미 경계를 정의하고 있다.
- 사용자(류준)가 직접 지정했다 — "내가 AI 를 담당할거고 민석님이 server 를 담당할거야".
- `decisions/011` 이 "충돌의 원인은 브랜치 수가 아니라 같은 티켓 동시 수정"이라고 정리했는데,
  담당 디렉터리가 갈리면 그 동시 수정 자체가 줄어든다.

## ⚠ 이름이 엇갈린다 — 혼동 주의

> **✅ 해소됨 (2026-08-26, `decisions/015`).** 브랜치를 `backend`→`ai`(류준) ·
> `ai`→`server`(장민석) 로 개명해 이름과 디렉터리를 일치시켰다. 아래에서 "바꾸면 룰셋의
> 필수 통과 검사 이름까지 함께 고쳐야 한다"고 적은 것은 **틀렸다** — 그 검사 이름은
> `test.yml` 의 job 이름이지 브랜치 이름이 아니어서, 실제로 고친 곳은 push 트리거 한 줄뿐이었다.
> 아래 본문은 그 시점의 판단이므로 그대로 남긴다(절대 원칙 8).
> **옛 기록의 `ai` 브랜치는 장민석**을 가리킨다는 사실은 지금도 유효하다.

브랜치 이름과 디렉터리 이름이 **서로 다른 사람을 가리킨다.**

| | 류준 | 장민석 |
|---|---|---|
| 브랜치 | `backend` | `ai` |
| 디렉터리 | `ai/` | `server/` |

즉 **장민석의 `ai` 브랜치에서 주로 고치는 것은 `server/`** 이고, **류준의 `backend`
브랜치에서 주로 고치는 것은 `ai/`** 다. `decisions/011` 로 브랜치는 넷을 유지하기로 했으므로
지금은 이름만 어긋난 상태다. 정리하려면 브랜치를 `ai`→`server`, `backend`→`ai` 로 바꿔야
하는데, 그러면 `test.yml` 트리거 목록과 **main 룰셋의 필수 통과 검사 이름**까지 함께 고쳐야
한다(룰셋은 `solidbob02` admin 몫). **팀 확인 전까지는 바꾸지 않는다** — 어긋난 이름은
헷갈릴 뿐이지만, 룰셋이 존재하지 않는 검사를 기다리면 PR 이 영원히 머지되지 않는다.

## 되돌리는 법

이 문서를 폐기하고 `decisions/005` 의 "둘이 함께, 기능별 분할 없음"으로 돌아간다.
디렉터리 구조는 그대로 두어도 된다 — 담당 배정만 없애면 된다.
`.claude/rules/rfp-harness.md` §2 의 R&R 표를 `류준 · 장민석 | 공동` 한 줄로 되돌린다.
