# 101 — `STATE.md` 에 세션 기록을 쌓지 않는다

**작성일**: 2026-08-27
**작성**: 정성윤
**상태**: 확정 — 반영 완료
**갱신 대상**: `CLAUDE.md` §0·§0.5·§3 · `_project/STATE.md`
**관련**: `decisions/016`(진행 기록을 파일 1개씩으로 가른다 — 같은 문제, 같은 해법)

> 담당자별 번호대(`decisions/022` ④)를 처음 쓴 문서다. 정성윤 = `1xx`.

## 맥락

`_project/STATE.md` 가 **809줄 · 세션 헤더 24개**로 불어났다. 네 사람이 매 세션
**맨 위에 자기 블록을 끼워 넣고**, 6행의 「최종 갱신」 한 줄을 **각자 덮어썼다.**

Git 3-way 병합은 양쪽이 **같은 위치에 서로 다른 내용을 넣으면** 번호가 겹치지 않아도
무조건 충돌로 넘긴다. 결과가 이것이다.

```
전체 커밋 63건 중 머지 커밋 19건 (30%)
2026-08-27 네 브랜치 통합 — 네 번 모두 이 파일에서 충돌
「최종 갱신」 한 줄 — 그 네 번 전부에서 충돌
```

**그리고 중복이다.** 같은 날 `STATE.md` 에 세션 블록이 14개, `jekyll/_logs/` 에 파일이 58개
있었다. 같은 내용을 두 곳에 쓰고 있었고, `CLAUDE.md §4` 가 *"같은 내용을 세 곳에 적지 않는다"*
고 정해 둔 것과 **`§0.5` 종료 루틴이 서로 모순**이었다.

**`STATE.md` 자신은 원래 규칙을 적고 있었다** — *"팀이 함께 보는 기록은 `jekyll/_logs/`.
여기에는 그쪽에 적기 애매한 내부 사정만 남긴다."* **규칙이 틀린 게 아니라 아무도 안 지켰다.**

## 선택지

| | 방법 | 판단 |
|---|---|---|
| A | 파일을 사람별로 쪼갠다(`_logs/`·`_backlogs/` 처럼) | ❌ **"지금 상태"가 흩어져 목적을 잃는다.** 이 파일은 한 곳에서 전체를 봐야 한다 |
| B | 세션 기록을 빼고 **현재 상태만** 남긴다. 갱신은 덮어쓰기 | ✅ |
| C | 그대로 두고 충돌 날 때마다 손으로 푼다 | ❌ 이미 19번 했다 |

## 결정

**B. `STATE.md` 는 지금 상태만 담는다. 세션 기록은 `_logs/` 한 곳에만 쓴다.**

1. **「최종 갱신」 줄을 없앤다** — `git log -1 --format=%ai -- _project/STATE.md` 가 이미 갖고 있다.
   정보를 더하지 않고 충돌만 만들었다.
2. **세션 블록 24개를 `_project/STATE-archive.md` 로 옮긴다** — **한 글자도 고치지 않았다**
   (절대 원칙 8). 새 기록을 아카이브에 추가하지도 않는다.
3. **남는 것은 「영역별 상태」 표 등 덮어쓰는 구조다** — 각자 **자기 줄만** 고치면
   서로 다른 줄이라 충돌하지 않는다.
4. **`CLAUDE.md §0.5` 종료 루틴을 고친다** — *"다음 세션이 이어받을 상태를 갱신했는가"* →
   *"내 영역 상태가 **바뀌었으면 그 줄만** 고친다(안 바뀌었으면 안 건드린다)"*.

## 근거

**팀이 이미 두 번 푼 문제다.**

| 문제 | 해법 |
|---|---|
| `progress.markdown` 한 파일에 네 명이 맨 위 삽입 → 커밋 37건 중 **16건이 충돌** | `_logs/` 파일 분리 (`decisions/016`) |
| 칸반 표 하나를 네 명이 동시 편집 | `_backlogs/` 파일 분리 |
| **`STATE.md` 한 파일에 네 명이 맨 위 삽입** | **이 문서** |

`decisions/016` 이 `progress.markdown` 을 가를 때 `STATE.md` 는 손대지 않아 **충돌 지점이
그쪽으로 옮겨갔을 뿐**이었다(류준이 2026-08-27 로그에 지적).

다만 처방은 달라야 한다 — `_logs/` 는 시간순 기록이라 쪼개도 되지만, `STATE.md` 는
**"지금 상태"** 를 담는 인수인계 문서라 쪼개면 목적을 잃는다. 그래서 **파일 분리가 아니라
역할 복원**이다.

## 되돌리는 법

`_project/STATE-archive.md` 의 내용을 `STATE.md` 뒤에 다시 붙이고, `CLAUDE.md §0.5` 의
3번 항목과 아래 주석 블록을 원문(*"다음 세션이 이어받을 상태를 갱신했는가?"*)으로 되돌린다.
아카이브는 원본 그대로라 손실 없이 합쳐진다.
