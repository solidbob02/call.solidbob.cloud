# 013 — 고객 화면 스코프 확정

**작성일**: 2026-08-26
**상태**: 철회 — `_project/decisions/014-고객화면-스코프-재철회.md`

> 번호 안내: 팀 ADR `006-db-스키마`·`007-도메인-라우팅`과 겹치지 않게 008로 둔다.

## 맥락

[2.1절](/docs/02/)은 상담원용 3분할 화면(자막 / 추천 카드 / 경고)만 명세돼 있고,
고객이 보는 별도 화면은 문서화된 적이 없었다.

## 선택지

1. 상담원 화면만 (현재 문서 기준)
2. 고객 화면 추가 — 키워드 감지 시 카드뉴스 팝업

## 결정

**2번.** 고객 화면을 추가한다. 상담원 대시보드와 같은 통화 세션(`call_id`)을 공유하고,
같은 인터페이스 계약([7.3절](/docs/07/) v2)의 `cards` 이벤트를 받아서 렌더링하되,
표시 방식은 다르다.

| | 상담원 (`apps/dashboard`) | 고객 (`apps/customer`) |
|---|---|---|
| 자막 · 대화 | 3분할 왼쪽 패널에 표시 | **표시하지 않음** (상담원 화면에만) |
| 카드 | 사이드바 목록 (계속 누적) | 키워드 감지(=카드 이벤트 도착) 시 **카드뉴스 팝업**. **3초 내 노출** |

프론트가 키워드를 따로 분류하지 않는다. 검색 트리거가 보낸 `cards` 이벤트가
곧 노출 신호다. mock 데이터는 7.3절 예시값만 쓴다. 대화 원문은 고객 화면에
그리지 않는다.

## 후속 확정 (2026-08-26)

고객 화면에서 실시간 자막을 빼기로 재확인했다. 팝업은 모서리 책갈피가 아니라
화면 중앙 카드뉴스 오버레이다. 대화는 `apps/dashboard` 에만 남긴다.

## 근거

조서희(프론트엔드) 확인 — 원래 기획 의도가 고객 화면 포함이었으나 문서화가 누락됨.

## 되돌리는 법

- `jekyll/docs/02` §2.1을 상담원 단일 화면 기준으로 되돌린다.
- `.claude/rules/customer.md`, `jekyll/_backlogs/w1-customer-scaffold-seohee.md` 를 제거한다.
