# 지식베이스 — 한별텔레콤(가상 사업자)

[데이터 확보 계획 5.1절](/docs/05/)에 따라 팀이 직접 작성하는 문서다. 실제 통신사 약관을
전재하지 않고, 가상 사업자 "한별텔레콤" 기준으로 처음부터 작성한다 — 저작권 문제가
없고, 프로젝트가 원하는 규칙(C-1~C-4 위반 유형, F-2 필수 확인 항목)을 정확히 반영하도록
설계할 수 있다.

## 문서 3종

| 폴더 | 문서 | 역할 |
|---|---|---|
| `terms/` | 요금제 약관 | B(검색) 대상. 화면에 "출처: 요금제약관 N.N조"로 인용됨 |
| `manual/` | 응대 매뉴얼 | B(검색) 대상. F-2 근거로도 쓰임 ("응대매뉴얼 N장") |
| `policy/` | 내부 처리 규정 | **F-2 게이트가 직접 참조**하는 처리유형별 필수 확인 항목 정의 |

세 문서 다 **같은 Elasticsearch 인덱스**에 적재된다([아키텍처](/docs/03/)) — 별도 인덱스를
만들지 않는다.

## ID 체계

각 조항/장 앞에 `<!-- id: ... -->` 주석으로 문서 ID를 붙여뒀다. 나중에 `services/core`
청킹 스크립트가 이 주석을 기준으로 조항 단위 청크를 잘라 인덱싱한다.

- 요금제 약관: `TERM-<장>.<조>` (예: `TERM-3.2`)
- 응대 매뉴얼: `MANUAL-<장>.<절>` (예: `MANUAL-7.1`)
- 내부 처리 규정: `POLICY-<처리유형>-<항목>` (예: `POLICY-CANCEL-1`)

## 화면 인용과의 일치

사이트 곳곳의 예시가 이 문서의 실제 내용을 인용하도록 맞춰뒀다.

| 예시 위치 | 인용 | 이 문서의 실제 내용 |
|---|---|---|
| [2.1 화면 구성](/docs/02/) | "요금제약관 3.2조, 유사도 0.87" | `terms/TERM.md` § 3.2 프로모션 할인 적용 시점 |
| [7.3 인터페이스 계약](/docs/07/) F-2 예시 | "응대매뉴얼 7장" | `manual/MANUAL.md` § 7장 해지 처리 절차 |
| [2.7 F. 종결 요건 검증](/docs/02/) | 해지=3건, 명의변경=2건, 보상=2건 | `policy/POLICY.md` |
